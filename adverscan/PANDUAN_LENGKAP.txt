================================================================================
  BAGIAN 1 — APA ITU ADVERSCAN?
================================================================================

AdverScan adalah laboratorium eksperimen yang membuktikan bahwa model
Machine Learning (ML) untuk keamanan jaringan bisa DITIPU oleh teknik
yang disebut "adversarial perturbation."

ANALOGI SEDERHANA:
  Bayangkan kamu punya detector anjing yang bisa membedakan foto anjing
  vs kucing dengan akurasi 98%. Tapi kalau kamu tambahkan noise kecil
  yang tidak kelihatan mata manusia ke foto anjing — detector itu
  tiba-tiba bilang "ini kucing."
  AdverScan melakukan hal yang sama, tapi untuk traffic jaringan:
  traffic serangan (attack) dimodifikasi sedikit supaya sistem IDS
  mengklasifikasikannya sebagai traffic normal (benign).

MASALAH YANG DIBUKTIKAN:
  - Model Random Forest dengan akurasi 92-98% di kondisi normal...
  - ...bisa turun ke 0-25% detection rate setelah adversarial attack
  - Artinya: serangan lolos tanpa terdeteksi!

SOLUSI YANG DIDEMONSTRASIKAN:
  - Adversarial Training: latih ulang model dengan contoh serangan
  - Feature Squeezing: kurangi presisi fitur untuk "menghapus" perturbasi
  - Kedua defense berhasil memulihkan detection rate ke 65-93%

3.3 MENGAPA PAKAI SURROGATE MODEL?
------------------------------------

MASALAH:
  Random Forest TIDAK bisa dihitung gradiennya karena:
  - Terdiri dari banyak decision tree (threshold-based, bukan continuous)
  - Tidak ada fungsi differentiable yang bisa di-backpropagation

SOLUSI — Surrogate / Transferability Attack:
  1. Train Logistic Regression pada data yang SAMA dengan RF
  2. LR punya gradient analitik yang mudah dihitung:
     gradient = p(attack) * coef
  3. Hitung perturbasi berdasarkan gradient LR
  4. Terapkan perturbasi yang sama ke sampel test
  5. Cek apakah RF juga tertipu (transferability)

KENAPA INI BERHASIL:
  - Kedua model dilatih pada fitur yang sama
  - Mereka belajar feature importance yang mirip
  - Perturbasi yang memindahkan sampel ke arah "benign" di LR
    seringkali JUGA memindahkan sampel ke arah "benign" di RF
  - Ini disebut "adversarial transferability" — konsep penting di dunia
    adversarial ML


3.4 MATEMATIKA FGSM (SEDERHANA)
---------------------------------

Untuk traffic attack (y=1) yang ingin diklasifikasikan sebagai benign (y=0):

  Loss yang diminimalkan:
    L = -log(p(benign | x))  =  log(1 + exp(w·x + b))

  Gradient loss terhadap input x:
    dL/dx = p(attack | x) * w
          = sigmoid(w·x + b) * w

  FGSM update:
    x_adversarial = x - epsilon * sign(dL/dx)
                  = x - epsilon * sign(p_attack * w)

  Interpretasi:
    - Jika w[i] > 0 (fitur i meningkatkan p_attack):
      kita KURANGI nilai fitur i (sign negatif)
    - Jika w[i] < 0 (fitur i menurunkan p_attack):
      kita TAMBAH nilai fitur i (sign positif)
    - Hasilnya: sampel bergerak ke arah "lebih mirip benign"


3.5 DEFENSE: ADVERSARIAL TRAINING
------------------------------------

Langkah:
  1. Generate X_adv_train = FGSM(surrogate, X_train, epsilon=0.1)
  2. Buat augmented dataset:
     X_aug = concat(X_train, X_adv_train)  -- dua kali lebih besar
     y_aug = concat(y_train, y_train)       -- label tetap sama
  3. Shuffle X_aug, y_aug
  4. Latih ulang RandomForest pada X_aug

  Hasilnya: model "melihat" contoh yang sudah diperturbasi saat training
  sehingga lebih tahan terhadap perturbasi serupa saat inference.


3.6 DEFENSE: FEATURE SQUEEZING
---------------------------------

Langkah:
  1. Untuk setiap fitur x_i:
     - Hitung range: [x_min, x_max]
     - Normalisasi ke [0, 1]
     - Quantize ke 2^n_bits level
     - Kembalikan ke range asli
  2. Gunakan x_squeezed untuk inference (tanpa retrain)

  Dengan n_bits=8 (256 level):
  - Perturbasi sangat kecil (< 1/256 dari range) akan dibulatkan ke nol
  - Perturbasi besar tetap ada → defense tidak sempurna
  - Zero retraining cost!

6.1 Epsilon (kekuatan serangan)
---------------------------------
  File : src/experiment.py  atau  run_experiment.py
  Baris: EPSILONS = [0.0, 0.05, 0.1, 0.2, 0.3, 0.5]

  Penjelasan:
  - epsilon = 0.0  : tidak ada serangan (baseline)
  - epsilon = 0.1  : serangan ringan
  - epsilon = 0.3  : serangan sedang (detection drop signifikan)
  - epsilon = 0.5  : serangan kuat (detection hampir nol)

  Ubah contoh: EPSILONS = [0.0, 0.1, 0.3, 0.5, 1.0, 2.0]
  (epsilon > 0.5 = serangan sangat kuat, perturbasi lebih terlihat)


6.2 Jumlah Fitur yang Dipilih
-------------------------------
  File : run_experiment.py  atau saat memanggil load_data()

  Contoh perubahan:
    X_train, X_test, ... = load_data(data_path, n_features=30)

  Default: 20 fitur (balance antara akurasi dan kecepatan)
  Range  : 10-78 fitur (lebih banyak = lebih lambat tapi lebih akurat)


6.3 Parameter Random Forest
-----------------------------
  File : src/model.py, fungsi train_random_forest()

  train_random_forest(X_train, y_train,
      n_estimators=100,  # jumlah pohon (lebih banyak = lebih lambat tapi akurat)
      max_depth=10,      # kedalaman pohon (lebih dalam = lebih fit ke data)
      random_state=42    # seed untuk reproduktibilitas
  )


6.4 Parameter PGD Attack
--------------------------
  File : run_experiment.py

  pgd_attack(surrogate, X_test, y_test,
      epsilon=0.3,    # radius maksimal perturbasi
      alpha=0.03,     # step size per iterasi (alpha < epsilon)
      num_steps=20,   # jumlah iterasi (lebih banyak = lebih kuat tapi lambat)
  )


6.5 Feature Squeezing Bit Depth
---------------------------------
  File : src/defender.py

  feature_squeezing_detection_rate(rf, X_adv, y_test,
      n_bits=8   # 4=agresif, 8=balanced, 16=hampir tidak ada efek
  )

  n_bits=4  : 16 level  -> hapus perturbasi besar tapi rusak fitur asli
  n_bits=8  : 256 level -> balance antara defense dan preservasi
  n_bits=16 : 65536 level -> hampir tidak ada efek squeezing

================================================================================
  BAGIAN 9 — KONSEP KUNCI UNTUK DIPAHAMI
================================================================================

ISTILAH             ARTI
---------           ----
epsilon (eps)       Kekuatan maksimal perturbasi adversarial.
                    Kecil (0.05) = tidak terlihat, tapi mungkin tidak efektif.
                    Besar (0.5) = sangat efektif tapi perturbasi terlihat jelas.

Detection Rate      Persentase traffic attack yang BERHASIL dideteksi sebagai attack.
                    92.5% berarti 7.5% attack lolos tanpa terdeteksi.

False Negative      Serangan yang tidak terdeteksi = SANGAT BERBAHAYA di IDS!
                    Adversarial attack bertujuan memaksimalkan False Negative.

Surrogate Model     Model pengganti (LR) yang digunakan untuk menghitung gradient
                    karena model utama (RF) tidak differentiable.

Transferability     Kemampuan perturbasi yang dibuat untuk model A untuk juga
                    menipu model B. Ini yang membuat black-box attack mungkin.

FGSM                Fast Gradient Sign Method. Attack satu langkah.
                    Lebih cepat, lebih sedikit perturbasi.

PGD                 Projected Gradient Descent. Attack banyak langkah.
                    Lebih lambat, lebih kuat, menghasilkan drop lebih dalam.

Adversarial         Latih model pada data asli PLUS data yang sudah diserang.
Training            Model jadi lebih robust karena "pernah melihat serangan."

Feature             Kurangi presisi setiap fitur sebelum inference.
Squeezing           Perturbasi kecil akan hilang setelah dibulatkan.
