# AdverScan — Adversarial ML Lab

**Proving that ML-based Intrusion Detection Systems can be fooled — and how to defend them.**

AdverScan is an end-to-end experiment that:
1. Trains a Random Forest IDS model on network traffic data (CICIDS2017)
2. Attacks it with FGSM and PGD adversarial perturbations
3. Shows how detection rate plummets from ~97% to ~30-50%
4. Applies two defenses (adversarial training + feature squeezing) to recover performance

## How the adversarial attack works

Random Forest is non-differentiable, so we cannot compute gradients directly.

**Solution — surrogate / transferability attack:**
1. Train a Logistic Regression model (surrogate) on the same data
2. Compute analytical gradient: ∂(-log p(benign)) / ∂x = p(attack) × w
3. Perturb attack samples in the direction that minimises p(attack) on LR
4. This perturbation transfers to RF because both models learn similar feature importance

**FGSM** (Fast Gradient Sign Method) — single-step:
```
x_adv = x + ε × (-sign(p_attack × w))
```

**PGD** (Projected Gradient Descent) — iterative:
```
for step in range(N):
    x_adv = x_adv + α × (-sign(grad))
    x_adv = clip(x_adv, x-ε, x+ε)
```

## Typical results (sample_data.csv, CPU, ~60-120s)

| Condition | Detection Rate |
|-----------|---------------|
| Baseline (no attack) | ~97% |
| FGSM ε=0.1 | ~70-80% |
| FGSM ε=0.3 | ~35-55% |
| PGD ε=0.3 | ~25-45% |
| After Adversarial Training | ~75-85% |
| After Feature Squeezing | ~65-80% |

*Results vary with random seed. Full CICIDS2017 dataset gives more dramatic drops.*

## Key concepts demonstrated

- **Adversarial transferability**: attacks on a surrogate model transfer to the target model
- **Feature-space attacks**: tabular data can be perturbed just like images — no special structure needed
- **Defense trade-offs**: adversarial training improves robustness but may reduce clean accuracy
- **Feature squeezing**: a lightweight, training-free defense against fine-grained perturbations
